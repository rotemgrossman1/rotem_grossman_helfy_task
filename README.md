# 🏥 Helfy Project

A full-stack web application built with a **React + Vite** frontend and a **Node.js + Express** backend.

---

## 🛠️ Project Setup & Installation

Follow these steps to set up and install all necessary dependencies for both the frontend (`client`) and backend (`server`).

### 1. Frontend Setup (React + Vite)

From the project root:

```bash
# Navigate into the client directory
cd client

# Install frontend dependencies
npm install
```

---

### 2. Backend Setup (Express Node.js)

Navigate back to the project root and configure the server:

```bash
# Navigate back to the root folder
cd ..

# Navigate into the server directory
cd server

# Initialize Node project (if package.json does not exist)
npm init -y

# Install core Express dependencies
npm install express cors dotenv

# Install development dependencies (auto-reloads on file changes)
npm install -D nodemon

# Install all packages
npm install
```
